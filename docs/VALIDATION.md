## 本轮修正

- 连续对话只向后端发送 `role/content`，不传 UI 修改标记，避免后续对话被严格 schema 拒绝。
- “整体换材质”包括台面，明确局部材质修改仍保留其他部件。
- 所有重复部件共享有限的材质和程序纹理，避免为每根竖纹重复上传木纹纹理。
- 移除外部字体下载，基本预览不依赖远程字体服务。
- 修正输入框换行显示，明确规则演示与后续工程阶段状态。
